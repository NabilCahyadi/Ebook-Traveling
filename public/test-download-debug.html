🛠️ Network Debugging Checklist

  1. Open DevTools: Press F12
  2. Click Network tab
  3. Clear previous requests (⚫ icon)
  4. Try one of the test methods above
  5. Look for request to /user/invoice/.../download
  6. Check Status Code: Should be 200 for success, 403 for auth error, 404 if route not found
  7. Check Response Content-Type: Should be application/pdf
  8. Check Response Preview: Should show %PDF at start if valid PDF
⚠️ Important: Keep the Network tab open while clicking test buttons. The request must complete before the response appears in the log.
